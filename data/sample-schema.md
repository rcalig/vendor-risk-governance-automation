## Vendor Risk Governance Data – Sample Schema

| Field Name            | Description                       |
|-----------------------|-----------------------------------|
| VendorName            | Vendor identifier                 |
| RiskTier              | Governance tier                   |
| AssessmentStatus      | Current assessment state          |
| LastAssessmentDate    | Most recent assessment date       |
| ReassessmentStartDate | Planned reassessment commencement |
| ReassessmentDueDate   | Expected completion date          |
